MyArtifact Design system · 1.0

Moss

A calm, paper-toned system for a local artifact studio. The chrome stays quiet and warm so the artifacts themselves, often dark and dense, carry the visual weight. Sage marks action and state; gold marks history and versions.

03 — UX patterns applied in the studio
Three-pane workspace
Library, canvas and an inspector for history and metadata. The inspector collapses with ] so the canvas can go wide.
History you can see
The version dropdown becomes a timeline with author, summary and line deltas. Picking an old version shows a read-only banner with Restore and Back to latest.
Keyboard first
⌘K command palette, 1–4 to switch views, ⌘S to save a version, J/K to step versions. Shortcuts are shown next to the actions they trigger.
Safe destructive actions
Delete moves into an overflow menu and asks for the slug. Restoring creates a new checkpoint, so it is reversible and says so.
Explicit save state
The code editor marks unsaved edits on the tab and in the commit bar, and the primary button names the version it will create.
Scannable library
Artifacts group by project, sort by recency and show relative time. Filters live behind one compact control instead of two chip rows.
