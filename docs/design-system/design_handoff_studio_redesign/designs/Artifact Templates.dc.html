Agent instructions

How agents should build artifacts

The full text lives in agent-kit/SKILL.md, an extended version of the skill that myartifact setup installs for Claude Code, Codex and Antigravity.

  1. 01Search firstRun artifact_list. Update an existing artifact instead of duplicating it.
  2. 02Pick a templateDashboard, report, diagram or mini-app. Keep its structure and spacing.
  3. 03Paste a theme blockReplace the text between theme:start and theme:end. No hex values anywhere else.
  4. 04Use real contentEvery number has a label and a unit. Empty states explain what goes there.
  5. 05Tag and pushUse a kebab-case slug and the tags template:id and theme:id.
  6. 06Summarise each versionWrite one imperative line under 72 characters: “Add regional breakdown chart”.
Design rules
Hierarchy
One 28px title, 14px semibold section heads, 13–14px body. Mono for numbers and eyebrows.
Colour
Accent for actions and positive change; highlight for emphasis or a second series; danger only for errors.
Surfaces
Cards are surface + 1px border + 10px radius. Nest content in sunken, not more borders.
Charts
One message per chart. Series in THEME.chart order. No vertical gridlines.
Layout
4px grid, max width ~64rem, collapses cleanly to 390px.
Access
4.5:1 text contrast (built into tokens), aria-labels on icon buttons, labelled inputs.
